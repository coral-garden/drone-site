# Source-bound copywriting

Write from approved evidence. Persuasion does not relax the truth boundary.

## Required inputs

- approved brief and intended audience;
- exact channel and format contract;
- source packet with paths, URLs, dates, and evidence labels;
- approved product, offer, CTA, and claim boundaries;
- applicable brand voice and channel rules;
- exact writable run path when a file output is required.

Do not draft when the offer, audience, evidence packet, or path is materially missing.

## Method

1. Build a drafting ledger before prose:
   - source fact or approved decision;
   - exact source and date;
   - allowed scope and qualification;
   - protected span, if exact wording matters;
   - intended copy use.
2. Protect quotations, customer wording, names, dates, numbers, units, prices, links, offer terms, disclosures, legal qualifiers, and defined terms. Never paraphrase a quotation as though it remained exact.
3. State the approved angle and reader job in one sentence. If the angle requires evidence not in the packet, stop and request it.
4. Outline the minimum argument the channel needs. Keep each claim tied to the drafting ledger.
5. Draft in the selected brand voice. Specificity must come from supplied evidence, not invented anecdotes or decorative detail.
6. Add a claim ledger for the finished draft. Classify each externally verifiable statement as supported, supplied context, assumption requiring approval, or unsupported.
7. Offer variants only when they test meaningfully different approved angles. Tiny wording changes are editing, not variants.
8. Run a self-check for factual drift, changed offer, hidden urgency, fabricated familiarity, unsupported superlatives, broken links, missing disclosure, privacy issues, and channel limits.
9. Return the draft, source facts used, claim ledger, protected spans, assumptions, and remaining publication checks.

## Output contract

- Draft or exact written path
- Approved angle and channel
- Source facts used
- Claim ledger
- Protected spans
- Assumptions and unsupported items
- Meaningful variants, only if requested
- Editor focus and publication checks

## Boundaries

Never invent proof, testimonials, customer stories, statistics, features, prices, guarantees, urgency, scarcity, links, recipient facts, or prior relationships. Do not browse, send, schedule, publish, change live systems, or use Humanizer as a source of facts. The formal Humanizer pass belongs after independent evidence review.
